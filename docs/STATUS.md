# Состояние Spotlight Pocket

Обновлено 11 ноября 2026 года после исправлений и браузерной проверки.

Рабочая папка: `C:\ai\vocabulary`.
Предыдущий чат: «Создать сайт для тренировки слов», ID `01a1c64c-7cd4-7810-9139-b653356773e6`.

## Задача

Мобильная тренировка слов Spotlight 8, модули 1 и 2, с произношением и офлайн-доступом. Требуется публикация для использования на телефоне в дороге.

## Реализовано в файлах

- Статическое приложение в `dist/`: три режима тренировки, словарь, фильтры, закладки, локальный прогресс.
- 686 словарных записей и 669 файлов озвучки Microsoft Zira.
- Service Worker, загрузка аудио для офлайн-доступа и возобновление загрузки.
- Локальный сервер, модульные и браузерные проверки.
- В `.openai/hosting.json` сохранён идентификатор Sites; наличие этого файла не подтверждает публикацию.

## Проверено сейчас

- Локальный адрес `http://127.0.0.1:4180` отвечает HTTP 200.
- `npm run check` проходит.
- `npm test`: все 8 тестов проходят, включая исходные записи, WAV-файлы и восстановление сохранённой тренировки.
- `restoreSession` реализована в `core.mjs` и подключена в `app.js`: повреждённая тренировка сбрасывается, корректные ответы и незаконченный ввод сохраняются.
- Кнопка паузы загрузки сохраняется в DOM при обновлении счётчика файлов.
- Браузерная проверка полностью проходит в Edge: три режима, исправление ответа, закладки, пауза и продолжение загрузки, фактическая готовность всего пакета, перезагрузка и звук без сети, HTTP Range, повреждённое сохранение и восстановление ввода.
- Проверены ширины 390, 360 и 1280 пикселей, без горизонтального переполнения и ошибок страницы.
- Скриншоты сохраняются в системной временной папке `spotlight-pocket-qa`, путь можно задать через `VOCABULARY_QA_OUTPUT`.
- Версия кэша приложения обновлена до `spotlight-shell-v3`, в офлайн-пакет включён `mobile.css`.
- Мобильная тренировка занимает видимую высоту окна с учётом visualViewport и safe-area; кнопка перехода остаётся на экране, длинный список вариантов прокручивается внутри своего блока.
- `node scripts/mobile-layout-test.cjs`: три режима, верные и неверные ответы, длинные варианты, самые длинные фразы и изменение высоты окна проверены при 393×700, 360×640 и 393×600 без прокрутки страницы для перехода к следующему слову.
- Предыдущий чат завершился ошибкой Codex `Bad Request`; это само по себе не является диагностикой сайта.
