# Spotlight Pocket — Spotlight 8 Vocabulary

Мобильный тренажёр слов Spotlight 8: модули 1 и 2, 686 словарных записей, 669 файлов произношения, три режима занятий и офлайн-доступ.

Сайт GitHub Pages: https://bakster01.github.io/SL8_vocabulary/

## Запуск локально

Нужен Node.js 20 или новее. Установка зависимостей для самого приложения не требуется.

```sh
npm start
```

Откройте http://127.0.0.1:4180.

## Проверки

```sh
npm test
npm run check
```

Браузерные проверки: `node scripts/browser-test.cjs` и `node scripts/mobile-layout-test.cjs`. Эти скрипты используют Edge и Playwright из среды Codex автора; для запуска на другом компьютере потребуется настроить их пути. Скриншоты сохраняются во временную папку `spotlight-pocket-qa`.

## На телефоне

1. Откройте сайт в Chrome, Samsung Internet или Safari.
2. Добавьте его на главный экран.
3. Откройте Offline → Download for offline и дождитесь Ready offline: 669 / 669.
4. Проверьте тренировку и звук в авиарежиме.

Пакет аудио занимает около 50 МБ. Прогресс и закладки хранятся в браузере на конкретном устройстве. При переходе со старого адреса Sites прогресс и скачанный пакет автоматически не переносятся.

## Структура

- `dist/` — готовый статический сайт, словарь и WAV-файлы.
- `tests/` — проверки логики и полноты данных.
- `scripts/` — браузерные проверки и подготовка иконок.
- `.github/workflows/pages.yml` — проверка и публикация GitHub Pages после push в main.

Произношение — синтез Microsoft Zira Desktop (English US). Ссылки на исходные словарные записи сохранены в `dist/data.json`. Исходный локальный проект: Spotlight 8.

## Обновление

Измените файлы в `dist/`. При изменении приложения увеличьте версию SHELL_CACHE одновременно в `dist/sw.js` и `dist/offline.js`; новые обязательные файлы добавьте в оба списка SHELL. Аудиокэш версионируется отдельно. После push в main GitHub Actions проверит проект и обновит сайт.
